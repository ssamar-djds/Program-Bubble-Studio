Excel columns: Space Name, Square Feet, Direct Access, Close To, plus optional Icons (Acoustic, Privacy, Nature, Sunlight), Cluster, Color Group, Notes and Quantity. List related spaces separated by commas. Drop a .xlsx or .csv here, or choose a file. No file? Start a blank program and add spaces one at a time.
Add a space A quantity above 1 adds that many copies, grouped in a cluster named after the space unless you name one. Link other spaces to the cluster name to draw one line to the whole group.
This is a sample program so you can see how the tool works. Load your Excel file or edit the rows below to replace it.

Bubbles are drawn as circles whose area equals the space's square footage. Give spaces a Color group (for example Work, Support, Building) to color them together; change a group's color below the table. Spaces without a color group keep their own color. Tick the boxes on the left to select several rows and change them all at once (Shift-click selects a range). Notes (like "(10 ppl)") print as an extra line in the bubble.
